## NCR address reference data

`ncr-psgc-reference.json` is derived from the Philippine Statistics Authority
Q2 2026 Philippine Standard Geographic Code snapshot, as of 30 June 2026. It
contains the 17 NCR localities and 1,715 barangays. The data notice and PSA
CC BY 4.0 attribution are in `frontend/src/lib/ncr-psgc-reference.LICENSE.md`.

`ncr-postal-reference.json` is a local snapshot of the NCR city postal-zone
tables collected on 2 October 2026. Those tables cite PHLPost, PSA, and city
government references. PHLPost's current official locator remains the
authoritative place to verify a code: https://phlpost.gov.ph/zip-code-locator/.
See `frontend/src/lib/ncr-postal-reference.LICENSE.md` for source details.

Both JSON files are bundled for frontend selection and server validation. The
application does not request address data from an external service at runtime.

## Nationwide address data (outside NCR)

`ph-geo.json` holds the PSGC regions, provinces and cities/municipalities (outside NCR), each with the postal
codes known for it. It is generated by `backend/scripts/build-ph-address-data.mjs` and copied to both
`backend/src/data/` and `frontend/src/lib/`. Barangay names live only in the frontend, one file per region in
`frontend/src/lib/ph-barangays/`, and are loaded lazily when a city is selected.

Sources (downloaded 13 October 2026; none are requested at runtime):

- **Geography** — the open PSGC API mirror of the Philippine Statistics Authority's PSGC
  (https://psgc.gitlab.io/api/): 17 regions, 81 provinces, 1,634 cities/municipalities, 42,046 barangays.
  The PSA site blocks scripted downloads; to re-verify, compare against the masterlist at
  https://psa.gov.ph/classification/psgc.
- **Postal codes (primary)** — PHLPost-derived `phzipcodes` dataset
  (https://github.com/jayson-panganiban/phzipcodes). It has no entries for Western Visayas, Central Visayas,
  Zamboanga Peninsula or BARMM.
- **Postal codes (fallback only)** — GeoNames postal codes for the Philippines (CC BY 4.0,
  https://download.geonames.org/export/zip/PH.zip), used only for cities the PHLPost-derived data lacks.
  Each city records its source in `zipSource` (`phlpost` or `geonames`).

Coverage at generation: 1,556 of 1,617 non-NCR cities have a postal code (968 PHLPost, 588 GeoNames); 61 have
none and are entered manually. Postal codes are city-level, so there is no barangay-level autofill outside NCR.
PHLPost's locator remains the authority: https://phlpost.gov.ph/zip-code-locator/. Because the postal data is
not exhaustive, the server validates only that a postal code is four digits outside NCR.

NCR keeps its own PSA Q2 2026 PSGC snapshot and PHLPost zone tables (`ncr-*.json`), described above.

## NCR barangay postal codes

`ncr-barangay-postal.json` maps each NCR barangay (PSGC code) to `{ codes, fallback? }`; `codes[0]` is autofilled.
It is generated by `backend/scripts/build-ncr-barangay-postal.mjs` from the two NCR files above plus the PSGC API's
barangay and sub-municipality lists (for Manila's districts).

- Exact entries (no `fallback`) come from matching the barangay name, or for Manila its district, to a PHLPost zone.
- `fallback: true` marks a default the user should confirm, because PHLPost assigns these codes by street or area
  rather than by barangay number. Split Manila districts default to their first code (Tondo 1012, Sampaloc 1008,
  Santa Cruz 1003, Santa Ana 1009), and other unmatched barangays (all of Caloocan and Pasay) default to the city's
  central post office. That is the same fallback Wikipedia's Metro Manila barangay list uses.
- A missing entry means no default exists (two Taguig barangays); the user picks from the city's codes.

Coverage at generation: 637 exact, 1,076 defaults, 2 manual, out of 1,715 NCR barangays.
