This NCR lookup data is derived from the Philippine Statistics Authority (PSA)
Philippine Standard Geographic Code snapshot as of 30 June 2026, distributed by
`@ianlabicani/geoph-lite` 2.0.0. The upstream data notice attributes the source
to PSA and records the PSA site's CC BY 4.0 terms:

The bundled NCR data contains all 1,715 PSA-listed NCR barangays grouped under
their 17 NCR localities. It contains administrative names and PSGC codes only.
